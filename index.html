CHECKLIST HARDENING

INICIO AUDITORÍAS CHECKLIST REPORTE

Propósito

Proporcionar una metodología ordenada, práctica y repetible para configurar de forma segura un sistema operativo, servidor, aplicación o red.

Cómo usar la herramienta

  1. Crea una auditoría para un activo en la página Auditorías.
  2. Abre la auditoría y marca cada control como pendiente, aplicado o no aplica.
  3. Cierra la auditoría y revisa o imprime el reporte.

Seleccione una de las opciones siguientes

Auditorías

Revisión de seguridad de un activo concreto.

Checklist

Lista de medidas de seguridad que se revisan, según su tipo.

Reporte

Resumen de la auditoría. Solo lee la auditoría y calcula un resumen para mostrar o imprimir.
